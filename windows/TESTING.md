# Проверка Windows-версии 0.3

Сборка и проверки логики выполняются на macOS; Windows, реестр, WinVerifyTrust,
UAC и операции с Office здесь не запускались. Публикация в GitHub Releases не выполнена.

Выполнены 66 проверок логики и дополнительная проверка распознавания ссылки на
реально загруженной странице Microsoft. Официальный ODT скачан во временный каталог;
содержимое CAB и метаданные setup.exe прочитаны без запуска EXE. В ресурсе версии
setup.exe указано OriginalFilename = Bootstrapper.exe; проверка учитывает это имя.
Криптографическую проверку WinVerifyTrust необходимо подтвердить на Windows.

## Проверки без изменения Office

| Сценарий | Ожидаемый результат |
| --- | --- |
| Запуск EXE после распаковки архива целиком | Две вкладки в стиле macOS; нет запроса администратора при запуске |
| Windows без Office | Диагностика сообщает об отсутствии записей |
| Office 2021 или 2024 | Правильный год по продукту, а не по номеру `16.0` |
| Microsoft 365 | Подписной продукт без ошибочного года выпуска |
| Click-to-Run и старая MSI-установка | Обе установки показаны; отдельные MSI-компоненты не скрывают основной Office |
| Пустой/отсутствующий Inventory | Резервный источник отмечен; сборка не подставляется из телеметрии |
| Ограниченный доступ к реестру | Есть замечание о неполной проверке |
| Только оставшиеся EXE Office | Показаны файлы и замечание; новая установка заблокирована |
| Сохранить JSON | Отчёт содержит время завершения диагностики и её результаты |
| Предпросмотр конфигурации | Верные редакция, язык, разрядность и ExcludeApp; отсутствуют Remove/RemoveMSI |
| Изменение редакции | Access и Publisher предлагаются только в соответствующих редакциях |
| Начальный выбор | Все флажки сняты; компоненты сгруппированы в основные и дополнительные |
| Выбрать всё доступное / снять всё | Выбираются только компоненты выбранной редакции; недоступные флажки не включаются |
| Проверить компоненты без пакетов | Доступность по каталогу; статус файлов по диагностике; подпись пакетов не заявляется проверенной |
| Проверить компоненты после загрузки | Подпись и сохранённая конфигурация перепроверены; доступность не зависит от временного отключения интерфейса |
| Статусы и прогресс | Загрузка и установка имеют отдельные сообщения; нет выдуманного процента загрузки Office |
| Минимальная ширина окна и масштаб 125–200% | Строки и кнопки читаемы; обе вкладки прокручиваются |
| Навигация клавиатурой | Tab, Space, Enter и переключение вкладок доступны; фокус кнопок виден |
| Отмена подтверждения | Внешние процессы не запускаются |

## Проверки загрузки

Эти сценарии создают папки и скачивают файлы, но не устанавливают Office.
Распаковка ODT выполняется только после проверки подписи Microsoft.

| Сценарий | Ожидаемый результат |
| --- | --- |
| Автоматическая подготовка | Ссылка ODT найдена на странице Microsoft; подписанный bootstrap распакован |
| Выбор setup.exe вручную | Копия проверена; оригинальный файл не изменён |
| Неподписанный или иной EXE | Запуск отклонён |
| Нет сети / изменившаяся страница | Понятная ошибка; доступен ручной выбор ODT |
| Отмена UAC | Нет сообщения об успешной загрузке |
| Сбой ODT /download | Код показан; кнопка установки не становится доступной |
| Успешный /download | Есть Office/Data, CAB и поток данных; prepared.json создан |
| Перезапуск программы | Сохранённую сессию можно выбрать через «Открыть скачанные пакеты» |
| Изменённый XML или описание пакета | Сессия отклонена |
| Смена компонентов после подготовки | Установка текущей сессии отключена; скачанные файлы сохранены |

## Проверки, которые изменяют установленный Office

Запускать отдельно, после явного решения выполнить конкретную операцию.
Перед восстановлением или переустановкой сохранить документы и закрыть Office.

| Сценарий | Ожидаемый результат |
| --- | --- |
| Установка на Windows без Office | Отдельное подтверждение, UAC, видимое окно Microsoft и выбор согласия с условиями |
| Установка при существующем Office | Блокировка без удаления и изменения состава старого пакета |
| Установка при неполной диагностике | Блокировка с объяснением |
| Быстрое восстановление Click-to-Run | Открыт список программ; пользователь выбирает продукт и действие Microsoft |
| Онлайн-восстановление / переустановка Click-to-Run | Действие выполняется в окне Microsoft; приложение не заявляет, что отслеживает результат |
| Восстановление MSI | Повторная проверка ProductCode, /fomus, /norestart; отображение результата |
| Переустановка файлов MSI | /famus того же продукта; нет предварительного удаления |
| Неполный/некорректный ProductCode, HKCU-продукт | Штатное окно программ вместо запуска команды по непроверенным данным |
| Отмена UAC или MSI | Отмена показана отдельно от ошибки/успеха |
| Код MSI 1612/1618/3010 | Нет источника / занят установщик / нужна перезагрузка показаны отдельно |
| Повторная диагностика после операции | Сопоставить записи и версии; отдельно проверить запуск приложений |

Для фиксации результата достаточно записать выпуск и разрядность Windows,
редакцию Office, выбранное действие, текст результата, отчёт диагностики
до/после и журнал operations.log для операций ODT.
