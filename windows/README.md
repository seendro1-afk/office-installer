# Office Installer для Windows — версия 0.3 для проверки

Windows-версия в том же репозитории, что и приложение macOS. Интерфейс:
«Установка Office» и «Восстановление Office». Реализованы диагностика,
подготовка и загрузка пакетов, запуск установки и штатные способы восстановления.
Проверены логика на искусственных данных и сборка; реальные операции, подписи,
UAC и GUI ещё предстоит проверить на Windows. Версия не опубликована в Releases.

## Запуск на Windows

Если подготовлен архив `windows/publish/OfficeInstaller-Windows-x64-v0.3.zip`,
распакуйте его целиком на Windows и запустите `OfficeInstaller.exe` из папки
`OfficeInstaller`. DLL рядом с EXE необходимы для WPF; сохраняйте их вместе.
Эта сборка содержит .NET и не требует SDK на компьютере пользователя.
Реальный запуск GUI и диагностика реестра проверяются отдельно на Windows.

Требуется Windows 10/11 и .NET 8 SDK для сборки:

```powershell
dotnet run --project windows/OfficeInstaller/OfficeInstaller.csproj
```

Команду выполнять из корня репозитория. Для запуска интерфейса и диагностики
права администратора не нужны; Windows запросит их при запуске ODT или MSI-восстановления.

Сборка отдельного приложения для 64-разрядной Windows:

```powershell
dotnet publish windows/OfficeInstaller/OfficeInstaller.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o windows/publish/win-x64-v0.3
```

Результат: `windows/publish/win-x64-v0.3/OfficeInstaller.exe`. Для этой сборки
на компьютере пользователя не требуется отдельно установленный .NET.
При переносе скопируйте всю папку `win-x64-v0.3`, включая соседние DLL.

## Интерфейс как в macOS-версии

Экран установки повторяет структуру `macos/ContentView`: параметры редакции,
основные приложения, дополнительные компоненты, проверка компонентов, загрузка,
установка и корпоративная лицензия. Компоненты расположены строками с флажками
и статусами. Изначально ничего не выбрано. «Выбрать всё доступное» выбирает
только компоненты текущей редакции; «Снять всё» сбрасывает выбор.

«Проверить компоненты» сверяет доступность с каталогом выбранной редакции,
читает сведения об установленных файлах Office и, если есть подготовленная
сессия, повторно проверяет подпись ODT и конфигурацию. Это не анализ содержимого
каждого компонента установочного пакета. Статус «Файл найден» основан на последней
проверке файлов и не означает, что приложение исправно.

Teams, Copilot и Defender отображаются как компоненты с отдельной установкой,
их флажки отключены. OneDrive доступен через ODT; Access и Publisher зависят
от редакции. Корпоративная лицензия описана отдельно: `.pkg` / VL Serializer
предназначены для macOS, отдельный активатор в Windows-приложение не добавлен.
Кнопок, имитирующих применение macOS-лицензии на Windows, нет.

Во вкладке восстановления сведения показаны в карточках с версиями и статусами;
технические подробности свёрнуты. Все Windows-действия восстановления,
переустановки, сохранения отчёта и открытия скачанных пакетов сохранены.

## Установка и загрузка

1. Выберите Office LTSC 2021/2024 Professional Plus или Standard либо Microsoft 365 Apps
   для бизнеса/предприятий, язык, разрядность и приложения. Access доступен только
   в редакциях, которые его включают; Publisher предлагается только для LTSC 2021.
   OneDrive — отдельный необязательный компонент. Новый Outlook, Teams, Copilot,
   Defender и отдельные продукты Visio/Project пока не устанавливаются.
2. «Показать конфигурацию» открывает XML без запуска внешних программ.
3. «Подготовить и скачать» создаёт новую сессию в
   `%LOCALAPPDATA%\OfficeInstaller\Sessions\<id>`. ODT загружается со страницы Microsoft;
   каждый переход проверяется по разрешённому HTTPS-хосту. Windows должна подтвердить
   цифровую подпись и издателя Microsoft Corporation. Затем ODT распаковывается в папку
   сессии и запускается с `/download` для получения Office с серверов Microsoft.
   Это загрузка, а не установка Office; ODT может запросить права администратора.
4. Если страница Microsoft изменилась или сеть недоступна, можно самостоятельно
   получить ODT по кнопке «Сайт Microsoft», распаковать его и выбрать `setup.exe`.
   Выбранный файл копируется в новую сессию и также проверяется перед запуском.
5. После загрузки кнопка «Установить» требует отдельного подтверждения. Перед
   `/configure` повторно проверяются подпись ODT, точное содержимое XML, базовые
   файлы пакета и отсутствие существующего Office. Существующий Office, найденные
   файлы без записей продукта или неполная диагностика блокируют новую установку.
6. «Открыть скачанные пакеты» позволяет выбрать `prepared.json` в ранее созданной
   сессии. Подпись и конфигурация перепроверяются; повторно скачивать Office не требуется.

XML не содержит `Remove`, `RemoveMSI`, `MigrateArch`, ключей или автоматической
активации. Не выбранные компоненты исключаются явно. Принудительное закрытие
приложений отключено; условия Microsoft показываются в установщике.
Изменение выбора сбрасывает готовность текущей сессии, сохраняя ранее скачанные файлы.
Все сессии и журнал `operations.log` остаются на диске; автоматического удаления нет.
При ошибке или тайм-ауте загрузки частичные файлы также сохраняются.

Программа показывает этапы работы и объём загрузки ODT. Процент загрузки самого
Office не вычисляется: публичного прогресса ODT для этого нет. Результат `/download`
и наличие основных файлов проверяются до готовности установки; целостность
содержимого пакетов Office проверяет установщик Microsoft, а не собственный парсер.

## Восстановление и переустановка

После диагностики выберите действие в карточке нужного продукта и подтвердите его.

- **Click-to-Run:** открывается штатный список установленных программ. Найдите
  указанный продукт, выберите «Изменить» и быстрое либо онлайн-восстановление.
  Переустановка текущего выпуска выполняется через онлайн-восстановление Microsoft;
  точная сборка может измениться и может потребоваться повторная активация.
  Программа не выдаёт открытие окна за успешно завершённое восстановление.
- **MSI с корректным ProductCode, установленный для компьютера:** после повторной
  диагностики запускается `msiexec /fomus {ProductCode} /norestart`. Переустановка
  использует `/famus` для всех файлов того же продукта, без предварительного удаления.
  Windows Installer может запросить исходные файлы. Коды отмены, занятого установщика,
  отсутствующего источника и необходимости перезагрузки показываются отдельно.
- **Установка для текущего пользователя, неизвестный тип или некорректный ProductCode:**
  открывается штатное окно программ для выбора подходящего действия вручную.

После операции повторите диагностику и проверьте запуск Office. Программа не
меняет Office 2021 на 2024 при восстановлении и не удаляет старые версии автоматически.

## Диагностика

- Читает Click-to-Run Inventory и Configuration в 32- и 64-разрядных представлениях реестра.
- Читает записи установленных программ HKLM и HKCU; не запускает команды из реестра.
- Предпочитает `OfficeProductReleaseIds` и `OfficePackageVersion` из Inventory.
  Если Inventory отсутствует, сообщает о резервном источнике Configuration.
  Значения телеметрии `VersionToReport` не используются для определения сборки.
- Определяет выпуск по идентификатору или названию продукта, а не по сборке `16.0`.
- Отдельно показывает найденные файлы Word, Excel, PowerPoint, Outlook, OneNote,
  Access, Publisher, Visio и Project в стандартных каталогах Office.
- Сообщает о недоступных разделах и неполных сведениях. Неизвестные значения
  остаются неизвестными; наличие записи или файла не доказывает исправность.
- Сохраняет отчёт JSON по выбору пользователя. В отчёте есть пути файлов и реестра,
  идентификаторы продуктов, сведения о версиях и замечания; ключи активации не читаются.
- Разделяет записи MSI для компьютера и текущего пользователя. Сетевые пути Office
  из реестра не обходятся; отсутствие доступа не выдаётся за отсутствие установки.

Проверка не пишет в реестр, не запускает Office, установщики, PowerShell или
WMI `Win32_Product`, не скачивает пакеты, не удаляет файлы и не меняет ОС.
Новый Outlook, Microsoft Store, переносные и нестандартные установки пока отдельно
не диагностируются. Язык и разрядность MSI пока не определяются. Список файлов
общий, без привязки к конкретной редакции.

## Границы поддержки

| Установка | Реализовано | Требует проверки на Windows |
| --- | --- | --- |
| Office LTSC 2021 / 2024 Click-to-Run | Диагностика, установка через ODT, переход в штатное восстановление | Загрузка, установка, онлайн/быстрое восстановление |
| Microsoft 365 Click-to-Run | Диагностика, установка через ODT, переход в штатное восстановление | Загрузка, установка, восстановление |
| Office 2019 / 2016 / 2013 Click-to-Run | Распознавание по идентификаторам, переход в штатное восстановление | Совместимость штатного восстановления |
| Старые MSI-установки | Диагностика, восстановление/переустановка по корректному GUID | Работа MSI и запрос исходных файлов |
| Неизвестные / нестандартные установки | Найденные сведения, переход в окно программ | Дополнительная диагностика |

Распознавание выпусков 2003–2024 и Microsoft 365 по записям не гарантирует
восстановления каждого выпуска. Новая установка розничных Home/Business-редакций,
старых выпусков, Visio и Project пока не реализована.

## Проверки логики

Проверки на искусственных данных доступны на Windows, macOS и Linux:

```sh
dotnet run --project windows/OfficeInstaller.Core.Tests/OfficeInstaller.Core.Tests.csproj
```

Это консольный набор проверок без внешних тестовых пакетов; он не читает реестр.
GUI, WinVerifyTrust, реестр, UAC, загрузку и операции Office необходимо дополнительно
проверить на Windows по [TESTING.md](TESTING.md).
