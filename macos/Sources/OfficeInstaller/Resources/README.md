# Application icons

Official Microsoft application icons are not included in this repository.

For local development, PNG icons can be placed in the `Icons` directory.

Expected filenames:

- word.png
- excel.png
- powerpoint.png
- outlook.png
- onenote.png
- onedrive.png
- teams.png
- copilot.png
- defender.png

If an icon is unavailable, the application displays a fallback symbol.

Microsoft trademarks and logos belong to their respective owners.
