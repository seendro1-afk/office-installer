# Office Installer для macOS

Русскоязычное приложение для выборочной установки Microsoft Office из официального установочного пакета Microsoft.

**Текущий релиз: [v1.0.1](https://github.com/seendro1-afk/office-installer/releases/tag/v1.0.1)** — macOS 14 или новее, Apple Silicon (M1 и новее).

[Скачать DMG v1.0.1](https://github.com/seendro1-afk/office-installer/releases/download/v1.0.1/OfficeInstaller-v1.0.1-macOS-arm64.dmg) · [Все релизы](https://github.com/seendro1-afk/office-installer/releases)

## Возможности

- Выбор Word, Excel, PowerPoint, Outlook и OneNote.
- Дополнительные компоненты: OneDrive, Teams, Copilot и Defender. Их доступность зависит от содержимого пакета Microsoft; отдельные приложения могут отсутствовать.
- Загрузка пакета с серверов Microsoft и проверка его цифровой подписи.
- Отображение установленных версий и доступности компонентов.

Windows-сборка в текущей версии проекта не опубликована, исходного каталога `windows` в ветке `main` нет. Поддержка Windows не входит в текущий релиз.

## Требования

- macOS 14 Sonoma или новее.
- Mac с Apple Silicon (M1 и новее). Готовая Intel-сборка не опубликована.
- Подключение к интернету для загрузки пакета Office.
- Права администратора для установки выбранных компонентов.
- Действующая лицензия Microsoft Office для использования Office.

## Установка и первый запуск

1. Скачайте [OfficeInstaller-v1.0.1-macOS-arm64.dmg](https://github.com/seendro1-afk/office-installer/releases/download/v1.0.1/OfficeInstaller-v1.0.1-macOS-arm64.dmg).
2. Откройте DMG и перетащите **Office Installer.app** в **Applications**.
3. Запустите Office Installer.

Релиз v1.0.1 использует ad-hoc подпись и не нотариализован Apple. Если macOS блокирует запуск, закройте предупреждение, откройте **System Settings → Privacy & Security**, нажмите **Open Anyway** для Office Installer и подтвердите запуск. Не отключайте Gatekeeper.

### Установка компонентов Office

1. Нажмите **«Скачать Office»** и дождитесь завершения загрузки и проверки подписи Microsoft.
2. Дождитесь автоматической проверки компонентов. При необходимости нажмите **«Проверить компоненты»**.
3. Отметьте доступные приложения или нажмите **«Выбрать всё доступное»**.
4. Нажмите **«Установить выбранное»**, проверьте список и подтвердите установку.
5. Предоставьте права администратора, дождитесь результата и проверьте запуск выбранных приложений.

### Проверка скачанного DMG

В Терминале выполните команду, указав путь к скачанному файлу:

```sh
shasum -a 256 ~/Downloads/OfficeInstaller-v1.0.1-macOS-arm64.dmg
```

Ожидаемый SHA-256 для v1.0.1:

```text
361efb9efc23c0324cd05f26032d9081764e30af6096b07a55708a53d6a75620
```

## Сборка из исходного кода

Требуются macOS, Xcode Command Line Tools и Swift 6. Из корня репозитория:

```sh
./build-macos.sh
```

Готовое приложение и DMG появятся в `macos/dist/`. Скрипт проверяет Info.plist, выполняет ad-hoc подписание приложения и проверяет подпись и образ DMG. Подпись Developer ID и нотариализация в этом скрипте не настроены.

## Обратная связь и план проверки

Если установка завершилась ошибкой, [создайте issue](https://github.com/seendro1-afk/office-installer/issues/new): укажите версию приложения, версию macOS, модель чипа, выбранные компоненты, этап сбоя и текст ошибки.

По результатам проверки владельца проекта, установка и запуск выбранных приложений Office прошли успешно на Mac с чипами **M1, M3 и M4**. Версии macOS, количество устройств и версия проверенной сборки не указаны. Сценарии, критерии, результаты и форма дальнейших проверок описаны в [плане пилота](docs/PILOT.md).
